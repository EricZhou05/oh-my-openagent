# 隐私政策

最后更新日期：2026年5月2日

本隐私政策旨在说明 oh-my-opencode 和 oh-my-openagent 如何收集、使用和保护与已发布的 CLI 包、OpenCode 插件以及适用的项目网站或仓库材料相关的信息。

在本政策中，“应用程序”指已发布的 `oh-my-opencode` CLI 包及其安装的 OpenCode 插件运行时。“服务”指应用程序与项目分发渠道的合称。“我们”和“我们的”指 oh-my-opencode 的维护者。“您”指服务的用户。

凡使用本服务，即表示您接受本隐私政策以及 [terms-of-service.md](./terms-of-service.md) 中随附的服务条款。

## 1. 我们收集的信息

我们收集有限的非个人信息，以用于运营和改进本服务。

### 自动收集的信息

在启用匿名遥测时，应用程序可能会收集单次匿名使用事件：

- `omo_daily_active`：在插件加载或调用 `run` 命令行界面（CLI）时，每台机器每个 UTC 日最多发送一次，用于估算每日、每周和每月的活跃安装量。
- 随该事件捆绑的匿名机器元数据：例如软件包版本、插件名称、运行时、操作系统系列、区域设置和时区。
- 派生自本地主机名单向哈希值的伪匿名安装标识符。

应用程序不会创建或更新 PostHog 个人画像，也不会通过此遥测路径收集提示词内容、源文件、仓库内容、访问令牌、API 密钥、原始主机名或运行时错误诊断信息。

### 配置与本地状态

应用程序会在您的机器上存储本地配置和遥测去重状态，以支持安装、配置和匿名每日活跃跟踪。

## 2. 遥测的工作原理

应用程序使用 PostHog 进行匿名产品分析。遥测默认启用，遵循与 cmux 相同的退出（opt-out）机制，且仅用于估算活跃安装量（每日、每周和每月），以便我们了解广泛的采用情况。

在运行 CLI 或插件宿主之前，您可以通过设置以下环境变量之一随时禁用遥测：

```bash
export OMO_SEND_ANONYMOUS_TELEMETRY=0
# or
export OMO_DISABLE_POSTHOG=1
```

禁用遥测后，将不会发送 PostHog 事件。

## 3. 第三方服务

本服务可能会使用第三方服务提供商，包括：

- **PostHog**：用于匿名产品分析。
- **npm** 和 **GitHub**：用于软件包分发、发布和仓库托管。
- **OpenCode** 以及您为自己智能体使用而单独配置的模型提供商。

每个第三方服务均有其自身的条款和隐私惯例。

## 4. 我们如何使用信息

我们将收集的信息用于：

- 估算每日、每周和每月的活跃安装量。
- 了解不同操作系统和软件包版本的总体采用情况。
- 维护和改进本服务。

我们不会出售通过此遥测路径收集的个人信息。

## 5. 数据保留

匿名分析数据的保留时间仅限于了解采用情况所合理必需的期限。存储在您机器上的本地遥测状态将一直保留，直至您将其删除。

## 6. 您的选择

您可以：

- 通过环境变量禁用匿名遥测。
- 从您的机器中删除本地配置或缓存的状态文件。
- 随时停止使用本服务。

## 7. 安全性

我们采取合理的管理和技术措施来保护我们控制的系统。任何传输或存储方法都无法保证绝对安全。

## 8. 本政策的变更

我们可能会不时更新本隐私政策。重大更新将通过修改本文档顶部的日期来体现。

## 9. 联系方式

关于本隐私政策的问题，应通过项目仓库的议题跟踪器（issue tracker）或仓库中公布的维护者联系渠道提出。
